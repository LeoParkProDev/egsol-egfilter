## 1. Tier A — 구매 의도 최상, 현재 완전 공백 ⭐ 최우선

가장 큰 구멍입니다. 지금 사이트는 "필터를 설명하는 콘텐츠"는 두꺼운데 **"사려는 사람이 검색하는 말"**이 거의 없습니다.

### A-1. 가격·견적 (전용 콘텐츠 0개)
```
헤파필터 가격 / 헤파필터 가격표 / 에어필터 단가 / 헤파필터 제작 비용
미듐필터 가격 / 프리필터 가격 / 필터 견적 받는 법 / 에어필터 가격 비교
```
현재 `/quote`는 폼만 있고 가격 관련 텍스트가 없어 이 검색군을 전혀 못 받습니다.
→ 제안 `/guide/air-filter-price` — **단가 공개가 아니라 "가격이 결정되는 구조"**(등급·규격·프레임 재질·수량·표준/비표준). 단가를 못 밝혀도 이 페이지는 성립하고, 오히려 견적 문의로 이어집니다.

### A-2. 비표준·주문제작 (핵심 차별점인데 페이지 없음)
```
비표준 헤파필터 제작 / 필터 주문제작 / 맞춤 사이즈 에어필터
특수규격 필터 / 필터 재단 제작 / 사이즈 없는 필터
```
llms.txt·README에는 있는데 **랜딩 페이지가 없습니다.** 경쟁사 재고에 없는 규격을 찾는 사람이 정확히 이 말로 검색합니다.
→ 제안 `/guide/custom-size-filter` 또는 `/custom` 랜딩

### A-3. 거래 조건 (B2B 결정 요인)
```
필터 세금계산서 / 에어필터 정기납품 / 필터 대량구매
관공서 필터 납품 / 조달 에어필터 / 사업자 필터 구매
```
FAQ에 일부 답이 있으나 검색 대응은 안 됩니다.
→ 제안: FAQ 확장 + `/guide/b2b-filter-supply`

## 2. Tier B — 문제해결·증상형 ⭐ 전환율 높음

검색량이 실하고 **답이 곧 교체 수요**로 연결되는 군입니다.

```
헤파필터 세척 가능한가 / 헤파필터 물세척      ← 답이 "불가"라 곧바로 교체 수요
프리필터 세척 방법 / 필터 재사용
필터 라벨 보는 법 / 필터 규격 읽는 법          ← 견적 프로세스와 직결(사진 보내기 유도)
공조기 필터 냄새 원인 / 에어컨 곰팡이 냄새
필터 차압계 보는 법 / 차압 게이지 기준
필터 방향 표시 / 에어플로우 화살표             ← 오설치 문의 다발
필터 교체했는데 먼지가 계속
```

특히 **`헤파필터 세척`**과 **`필터 라벨 보는 법`** 두 개를 강하게 추천합니다. 전자는 검색 의도와 사업 이해가 정확히 일치하고, 후자는 "라벨 사진 보내면 당일 견적"이라는 기존 프로세스로 자연스럽게 이어집니다.

→ 제안 `/guide/hepa-filter-washing`, `/guide/read-filter-label`, `/guide/filter-pressure-gauge`

## 4. Tier D — 제품군 확장

현재 4종. 실제 취급 가능 여부를 확인해야 합니다(**취급 안 하는 제품 페이지는 만들면 안 됩니다**).

```
카본필터 / 케미컬필터 / 탈취필터      ← 병원·도장·데이터센터와 연결
ULPA 필터 (U15~U17)                  ← 등급 가이드에 U 언급은 있으나 제품 없음
V뱅크 필터 / 미니플리트
백필터 (집진기)
그리스필터 / 후드필터                 ← 식품·주방
FFU                                   ← 여러 페이지에 언급만 되고 제품 페이지 없음
```
→ **어떤 걸 실제로 공급 가능한지 알려주시면** 그 범위 안에서만 만들겠습니다.

## 6. Tier F — 지역 키워드 ⚠️ 권장하지 않음

```
서울 헤파필터 / 경기 에어필터 / 부산 헤파필터 …
```
**반대 의견을 분명히 드립니다.** 지역별 실제 거점이나 차별화된 내용 없이 템플릿만 바꾼 지역 페이지는 구글의 doorway page(관문 페이지) 정책에 정면으로 걸리고, 적발 시 **사이트 전체 평가가 내려갑니다.** 지금까지 쌓은 자산을 걸 만한 대가가 아닙니다.

대신 같은 목적을 안전하게 달성하는 방법:
- `/about`에 배송 권역·리드타임을 구체적으로 명시
- Google Business Profile + 네이버 플레이스 등록 (지역 검색의 실제 작동 경로)
- 지역명이 자연스럽게 들어간 실제 납품 사례 콘텐츠

## 7. Tier G — 규격 숫자 롱테일 ⚠️ 조건부

```
610x610x292 헤파필터 / 595x595x290 / 610x610x150 / 570x570 / 305x305
```
검색 의도는 매우 정확하지만, 규격마다 페이지를 찍어내면 **내용이 거의 같은 얇은 페이지 수십 개**가 됩니다 — Tier F와 같은 위험입니다.

→ 안전한 대안: 기존 `hepa-filter-size-guide`를 **규격별 앵커 + 표 + 각 규격의 용도·재고 여부**로 확장. 한 페이지가 여러 규격 검색을 다 받습니다.

### 함께 처리한 것

- **"미디움필터" 표기 누락** — 사이트 전체에 0건이었음. `Product.aliases` 필드를 추가해 미디움필터·미디엄필터·중성능필터를 메타 키워드와 본문·FAQ에 반영. 프리(부직포필터)·헤파(HEPA필터)·롤(부직포롤)에도 별칭 적용
- **내부 링크 누락** — 홈 `Industries.tsx`와 `Footer.tsx`가 하드코딩이라 신규 14페이지로 가는 링크가 없었음. 전부 연결. 홈 그리드의 중복 링크(cleanroom·hvac 각 2회)도 제거해 고유 페이지로 재배치
- **실측 안내 상충 수정** — 신규 가이드에서 "프레임 안쪽을 재라"고 쓴 부분이 기존 규격표 가이드의 "필터 바깥 치수를 재라"와 반대였음. 잘못 주문될 수 있어 전 페이지를 "필터 바깥 가로×세로×두께(틀 끝에서 끝)"로 통일
- **`llms.txt` 갱신** — 기존 가이드 3편과 업종 4개가 통째로 누락돼 있었음. 신규분 포함 전면 재작성

### 근거를 검증한 규제 수치

본문에 쓴 법령 수치는 추정하지 않고 원문을 확인했습니다.

- **수술실** — 의료법 시행규칙 별표3·별표4 세부기준(2018.12.1 시행). 고위험도: 수술대 상부 천장 헤파 급기 → 벽 하단 배기, 층류형 / 중등도: 헤파 급기, 시간당 15회 이상, 층류 불필요 / 저위험도: KS B 6141 계수법 95% 이상, 15회 이상 + 외기 3회
- **취약계층 이용시설 유지기준** — PM-10 75㎍/㎥, PM-2.5 35㎍/㎥, CO₂ 1,000ppm, 폼알데하이드 80㎍/㎥, 총부유세균 800CFU/㎥, CO 10ppm. 의료기관·산후조리원·노인요양시설·어린이집 적용

시설 규모별 적용 범위는 관할 지자체 확인이 필요하다는 단서를 본문에 함께 넣었습니다.

sitemap·RSS·OG·스키마는 데이터 파일 기반이라 **전부 자동 반영**됐습니다.
