# 2026-09-28 스마트스토어 주문 목적 SEO 개선

## 목적과 변경 범위

최종 목적은 네이버 스마트스토어의 실제 주문 증가다. 홈페이지 검색 유입 → 맞는 규격/제품 선택 → 스마트스토어 상품/옵션 확인 경로를 개선했다. 스토어 상품명·가격·옵션·재고는 수정하지 않았다. 광고 집행과 Slack 알림도 하지 않았다.

- `/products` 제품 허브 신설: 제품군 4개와 규격 23개를 연결.
- 제품군·규격 상세: 구매 의도에 맞춘 고유 제목·설명, 상단 스토어 구매 버튼, 사양별 링크.
- 홈·헤더·모바일 바·가이드: 스마트스토어 진입을 우선 표시하고 비표준 규격은 견적 문의로 보조.
- 카탈로그의 실제 판매자 코드와 일치하는 링크만 연결. 중복 코드·미확인 항목은 제품군 페이지로 안내.
- 부직포롤의 두께·폭·길이 표기 통일. 롤 도면 설명과 구조화 데이터 단위 수정.
- 사이트맵에 제품 허브 추가, 근거 없는 자동 최신 수정일 제거.
- GA4 `smartstore_click`에 버튼 위치·제품군·상품 코드·안전한 목적 경로 추가. 주문 이벤트로 가장하지 않음.

## 실제 카탈로그 확인

2026-09-28 네이버 커머스 API를 읽기 전용으로 조회했다. 관련 상품 41개 중 37개는 `SALE` + `ON`, 4개는 판매 상태지만 `SUSPENSION`이었다. 중지된 부직포롤 개별 상품에는 직접 연결하지 않는다.

B_ALL `6473413080`의 4개 옵션은 표시 규격과 `sellerManagerCode`가 일치했다. 다른 B_ALL `6391368761`은 옵션 코드가 비어 있어 자동 매핑 대상으로 쓰지 않는다. 링크 이동이 옵션 자동 선택을 뜻하지 않으므로 구매자는 표시된 규격을 스토어에서 직접 선택해야 한다. 기본가격·추가 옵션가격을 홈페이지에 복제하지 않는다.

공개 상품 URL은 네이버 공식 `/main/products/{channelProductNo}` 형식을 사용한다. 브라우저에서는 로그인 화면으로 이동해 상품 상세의 최종 렌더링을 확인하지 못했으며, 코드·판매/전시 상태 확인 근거는 인증된 판매 API다. 스냅샷 이후의 품절·판매 종료는 보장하지 않는다.

- [상품 검색 API](https://apicenter.commerce.naver.com/docs/commerce-api/current/search-product)
- [상품 상세 API](https://apicenter.commerce.naver.com/docs/commerce-api/current/read-origin-product-product)
- [공개 상품 URL 형식](https://developers.naver.com/notice/article/15924)

## 성과 판단

검색 순위와 주문 증가의 결과는 아직 측정하지 않았다. 배포 전후 동일 기간의 실제 주문번호 수를 비교하고, 유입·스토어 클릭은 보조 지표로 본다. GA4만으로 스토어 내 결제 여부를 알 수 없으며, 판매자센터에서 검증된 귀속 자료가 없으면 홈페이지가 만든 주문이라고 단정하지 않는다.

상세 측정 방법과 남은 GA4 관리자 설정은 `smartstore-measurement.md`를 참고한다. 기술 검증과 배포 결과는 아래에 별도 기록한다.

## 기술 검증·배포

- 변경 파일 ESLint, TypeScript `--noEmit`, `git diff --check` 통과.
- `next build --webpack` 통과: 223개 정적 생성 대상 처리. 이미지 경로도 포함된 수치이며 SEO 콘텐츠 223편을 새로 만든 것은 아니다.
- `check-store-analytics.mjs` 통과: 외부 도메인 판정, 개인정보형 문자열 차단, URL 쿼리 배제, 상품 경로 허용 검증.
- 로컬 프로덕션 서버에서 `check-store-seo.mjs` 통과: 허브 1개 + 제품군 4개 + 규격 23개, 제목·설명 중복/누락, canonical, H1, 사이트맵, 상품 코드별 목적 URL 검증.
- 매핑 33개 모두 라이브 API 스냅샷의 코드·URL·판매/전시 상태 또는 B_ALL 옵션 라벨과 대조해 일치 확인.
- Chrome 320px에서 홈·제품 허브·B_ALL 롤 규격·H13/H14 가이드 가로 넘침 없음. 768px·1280px 헤더 겹침 없음. 버튼과 수동 옵션 선택 안내 확인.
- 독립 Luna high 리뷰에서 발견한 하이픈 전화번호 형태의 추적값 유출 가능성을 수정하고 회귀 검사 통과. 최종 리뷰 추가 지적 없음.
- 검사 스크립트 실행 시 Node의 module type 추론 경고가 있으나 종료 코드는 0이다. 앱 설정은 불필요하게 변경하지 않았다.

배포 상태: 검증 완료, 프로덕션 배포 및 실제 URL 검증 예정. 배포 성공과 실제 주문 증가를 혼동하지 않는다.
