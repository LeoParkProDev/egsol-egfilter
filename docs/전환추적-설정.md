# 전환 추적 설정 (사장님용)

광고를 다시 돌릴 때 **문의가 몇 건, 어느 키워드·경로에서 왔는지** 숫자로 보기 위한 설정입니다.
아래 ID 두 개만 발급받아 Vercel에 넣으면 끝납니다. **코드는 손댈 필요 없습니다.**

> ID를 넣지 않아도 사이트는 지금 그대로 정상 동작합니다. 분석 스크립트가 아예 안 붙을 뿐입니다.
> 즉, 급하지 않으면 나중에 해도 되고, 하나만 먼저 해도 됩니다.

---

## 1단계 — 구글 애널리틱스(GA4) 측정 ID 받기

1. <https://analytics.google.com> 접속 → 구글 계정 로그인
2. 왼쪽 아래 **관리(톱니바퀴)** → **만들기 → 속성**
   - 속성 이름: `에버그린필터`
   - 시간대: `대한민국`, 통화: `대한민국 원`
3. 업종·규모는 대충 골라도 됩니다 → **만들기**
4. 플랫폼 선택에서 **웹** 클릭
   - 웹사이트 URL: `evergreen-filter.vercel.app`
   - 스트림 이름: `에버그린필터 홈페이지`
5. 만들어진 화면에 **측정 ID**가 보입니다. `G-` 로 시작하는 값입니다.
   예) `G-ABCD123456`
6. 이 값을 복사해 둡니다.

> 나중에 다시 찾으려면: 관리 → 데이터 스트림 → 웹 스트림 클릭 → 오른쪽 위 측정 ID

---

## 2단계 — 네이버 프리미엄 로그분석 ID 받기

네이버 검색광고를 돌릴 때 "이 키워드가 문의로 이어졌는지"를 보는 도구입니다. **무료**입니다.

1. <https://searchad.naver.com> (네이버 검색광고) 로그인
2. 상단 **도구** → **프리미엄 로그분석**
3. **사이트 등록** → `https://evergreen-filter.vercel.app` 입력 → 등록
4. 등록되면 **공통 스크립트**가 나옵니다. 그 안에서 이 한 줄을 찾습니다.

   ```
   wcs_add["wa"] = "s_1a2b3c4d5e6f";
   ```

5. 따옴표 안의 값(`s_1a2b3c4d5e6f` 같은 문자열)만 복사해 둡니다.
   **스크립트 전체가 아니라 이 값만** 필요합니다.

> 전환 추적을 쓰려면 프리미엄 로그분석 화면에서 **전환 추적 사용**이 켜져 있어야 합니다.

---

## 3단계 — Vercel에 등록하고 재배포

1. <https://vercel.com> 로그인 → 프로젝트 **egsol-egfilter** 선택
2. **Settings → Environment Variables**
3. 아래 두 개를 추가합니다. (Environment는 **Production / Preview / Development 모두 체크**)

   | Key | Value |
   |---|---|
   | `NEXT_PUBLIC_GA_ID` | 1단계에서 복사한 `G-…` 값 |
   | `NEXT_PUBLIC_NAVER_WCS_ID` | 2단계에서 복사한 `wa` 값 |

4. **Deployments** 탭 → 맨 위 배포의 `⋯` → **Redeploy**
   (환경변수는 재배포해야 반영됩니다. 저장만 하면 아무 일도 일어나지 않습니다.)

---

## 4단계 — 제대로 붙었는지 확인

### 구글 애널리틱스

1. 휴대폰이나 다른 브라우저로 <https://evergreen-filter.vercel.app> 접속
2. GA4 → **보고서 → 실시간**
3. **지난 30분간 사용자 1명**이 잡히면 성공입니다. (1~2분 걸립니다)
4. 이어서 **견적 문의 폼**을 테스트로 한 건 보냅니다.
5. 실시간 보고서 아래 **이벤트 수(이벤트 이름별)** 에 `quote_submit` 이 뜨면 전환 추적까지 성공입니다.

### 네이버 프리미엄 로그분석

1. 같은 방식으로 사이트에 접속하고 견적 폼을 한 건 보냅니다.
2. 검색광고 → 도구 → 프리미엄 로그분석 → **전환 분석** 리포트
3. **반영에 몇 시간~하루 걸립니다.** 바로 안 보인다고 잘못된 게 아닙니다.
4. 하루 지나도 0이면 2단계의 `wa` 값을 다시 확인해 주세요.

## 5단계 — 광고 URL에 유입 표시 붙이기

문의 메일에 "유입 경로 / 검색어"가 찍히려면 광고 링크에 표시가 붙어 있어야 합니다.

- **네이버 검색광고**: 자동으로 붙습니다.
  검색광고 관리 화면에서 **추적 URL(자동 추적) 사용**이 **ON** 인지만 확인하세요.
  켜져 있으면 네이버가 `?n_media=…&n_query=검색어` 를 알아서 붙여 줍니다.

- **구글 광고**: `gclid` 가 자동으로 붙습니다. 따로 할 일 없습니다.

- **블로그·문자·전단지 QR 등 직접 만든 링크**: 뒤에 손으로 붙여 주세요.

  ```
  https://evergreen-filter.vercel.app/quote?utm_source=blog&utm_medium=post&utm_term=수술실필터
  ```

  | 붙이는 값 | 뜻 | 메일에 찍히는 곳 |
  |---|---|---|
  | `utm_source` | 어디서 왔는지 (blog, sms, flyer …) | 유입 경로 |
  | `utm_medium` | 형태 (post, cpc, qr …) | 유입 경로 뒤에 `/` 로 붙음 |
  | `utm_term` | 키워드 | 검색어 |

## 무엇이 기록되나

견적 문의 메일 아래쪽에 이런 블록이 함께 옵니다.

```
유입 경로: naver-ad
검색어:    수술실 헤파필터
랜딩:      /medical/operating-room
참조:      search.naver.com
```

판별할 수 없으면 `유입 경로: (미확인)` 한 줄만 찍힙니다.

분석 도구에는 아래 다섯 가지가 기록됩니다.

| 기록되는 행동 | 언제 |
|---|---|
| `quote_submit` | 견적 폼이 정상 접수됐을 때 (네이버 전환 = 신청/예약) |
| `quote_fallback` | 서버 장애로 공유·메일 앱 경로로 넘어갔을 때 (네이버 전환 = 신청/예약) |
| `kakao_click` | 카카오톡 채널 링크를 눌렀을 때 (네이버 전환 = 기타) |
| `phone_click` | 전화번호를 눌렀을 때 (네이버 전환 = 기타) |
| `smartstore_click` | 스마트스토어 링크를 눌렀을 때 |

**고객이 입력한 이름·전화번호·이메일·문의 내용은 구글·네이버 어디에도 보내지 않습니다.**
분석 도구로 나가는 값은 유입 경로·검색어·페이지 주소뿐입니다.

## 문제가 생기면

| 증상 | 확인할 것 |
|---|---|
| GA4 실시간에 아무도 안 잡힘 | Vercel 환경변수 저장 후 **Redeploy** 했는지 / 값이 `G-` 로 시작하는지 / 광고 차단 확장이 켜져 있지 않은지 |
| 메일에 `유입 경로: (미확인)` 만 계속 나옴 | 광고를 안 돌리는 중이면 정상입니다. 직접 주소를 친 방문은 `direct` 로 찍힙니다 |
| 네이버 전환이 하루 지나도 0 | `wa` 값 오타 / 프리미엄 로그분석에서 사이트가 **승인** 상태인지 |
| ID를 빼고 싶다 | Vercel에서 환경변수를 지우고 Redeploy 하면 스크립트가 완전히 사라집니다 |
